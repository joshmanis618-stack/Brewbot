Step progression

Steps run in order. Click Start Step on a pending step to make it active. When the work is done, click Complete to move on. If you need to skip a step (for example if a sensor trigger is not available), click Skip.

Device commands

When you start a step, Brewbot immediately sends any device commands defined on that step — for example, opening a valve or turning on a pump. Commands are sent over MQTT so your hardware controller receives them in real time.

Step colors
  • Yellow border — the currently active step.
  • Green border — a completed step.
  • Faded — a skipped step.
  • Grey border — pending steps not yet started.
No program shown?

If this page shows "No automation program linked," go to Brew Programs, create a program, and link it to this recipe using the Linked Recipe dropdown. Then return to your brew session.
