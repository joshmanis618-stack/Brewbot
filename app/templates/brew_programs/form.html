What is a brew program?

A brew program is an ordered sequence of steps that Brewbot executes during a brew day. Each step can send commands to hardware devices (valves, pumps, heaters) and wait for a trigger condition before advancing to the next step. Link a program to a recipe so it appears automatically in that recipe's brew session.

Trigger types
  • Manual — the brewer clicks Start Step to advance. Use this for any action that needs human judgment.
  • Timer — automatically advances after a set number of minutes once the step is started.
  • Temp Above — advances when a sensor reading rises above the specified temperature threshold.
  • Temp Below — advances when a sensor reading falls below the specified temperature threshold.
  • Flow Volume — advances when a flow meter reports that the specified volume (in liters) has passed.
Device commands

Each step can send one or more commands to registered devices when the step becomes active:

  • open / close — for solenoid valves.
  • on / off — for pumps, heaters, or any switched device.
  • setpoint:NNN — sends a temperature setpoint (e.g., setpoint:68.5) to a heater controller.

Commands are published over MQTT to brewbot/{device_key}/command as soon as the step starts.
