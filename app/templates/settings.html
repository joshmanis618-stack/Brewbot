Backup formats
  • JSON backup includes everything: recipes, ingredients, equipment, rig profiles, devices, brew programs, and brew sessions.
  • BeerXML includes recipes only (ingredients are created in the library as needed). Brew sessions and programs are not included.
Import is always safe

Both import methods are append-only — no existing data is deleted or overwritten. Ingredients and equipment are matched by name; recipes are always added as new entries.

Migrating to a new server
  1. Export a JSON backup from this page.
  2. Move your Docker volume or use pg_dump to transfer the database, or start fresh on the new server.
  3. On the new server, go to Settings and import the JSON backup file.
